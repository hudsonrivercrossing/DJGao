# V102 真机验证记录：DJ 生日编曲

日期：2026-11-19 · 对应设计文档 [`2026-11-19-birthday-song-and-share-design.md`](superpowers/specs/2026-11-19-birthday-song-and-share-design.md) 第 7 节「真机验证清单」第 1–10 项。

## 这份记录是怎么来的

没有在装了 Baud Girl V102 的真机上实际操作过任何一项。结论分两种来源：

- **手册**：V102 手册 [baudgirl.com/work/FM-1+VA/manual/102](https://baudgirl.com/work/FM-1%2BVA/manual/102) 已经把问题说清楚的，直接给结论，并标出章节（§）。这类结论说明「固件按手册应当这样」，不等于听过。
- **未测**：手册没有说，或者只能靠耳朵判断的，记为「未测（需要 V102 真机）」，并在下面写出以后在真机上要跑的步骤。

另外已有的背景：`docs/birthday-hardware-research.md` 已经假设 V102 8‑Bit 的 OCT +2 键位和 F0/F♯0/G0 的底鼓/军鼓/踩镲（里面也说「先试听，鼓位可改」）；在真机上测之前，要先 `EDIT → Erase Preset → 8-Bit` 初始化一个空预设。

## 结果

合计：4 通过、1 不通过、5 未测。

| 项目 | 结论 | 操作 | 依据 |
| --- | --- | --- | --- |
| 1 默认 8‑Bit 鼓组每个鼓的键位（拍掌、开镲、镲片、噪音鼓位） | **未测（需要 V102 真机）** | 见下方「未测步骤」1 | 手册只说了：鼓共 12 个，在 F0–E1（§6.1.1），每个鼓有 Wave / Pitch / Sweep / Decay / Level / Snap / Choke 七行可改（§6.2.1），新预设里闭镲、开镲、金属镲在同一个 choke 组 A（§6.2.3）。哪个键是拍掌、哪个是镲片，手册没有逐个列出。底鼓 F0、军鼓 F♯0、闭镲 G0 沿用 `birthday-hardware-research.md` 的约定 |
| 2 pattern Rate 能否选 1/8T、1/16T，及对播放的影响 | **通过（手册）**；接缝处的实际听感未测 | 每个 pattern 自己设 SEQ → Timing → Rate | Rate 范围 1/1 到 1/32T，每个 pattern 各有一个（§9.14.2）；Rate 决定一步的长度，速度本身仍是全局 Tempo（§9.14.2、§10.1）。所以 124 BPM 下 1/16T 一拍 6 步，是 1/16 的 1.5 倍（约 186 BPM 的听感）；1/8T 一拍 3 步，比 1/16 慢到四分之三，124 BPM 约等于 93 BPM，样片取 96 BPM，差约 3%。换 pattern 在最后一步准点接上（§9.15）。注意：只含空步的 pattern 每次开机会回到 1/16（§9.8.6、§9.14.4），所以有音符的 pattern 才能保住 Rate |
| 3 Seq / 单步 Transpose 与「每 pattern 不同 Key 的 preset」是否影响鼓 | **不通过**（作为升调手段）；对鼓的影响未测 | 见「未测步骤」2 | (a) Seq Transpose 是全局的，所有 16 个 pattern 一起动，不能只给 drop 升调（§9.14.3）。(b) 预设的 Key 只决定每个键弹出什么和弦，不会把旋律移调；主奏键仍然最先、最低发声（§6.5、§6.6）。所以「drop 用 Key D 的 preset」做不到升一个全音。(c) 单步 Transpose 范围 −24 到 +24，只动这一步（§9.11.1），但这一步里的鼓也在同一步，鼓是否跟着移没有写。鼓只在 F0–E1，低于 F0 的音不发声（§6.1.1），移调很可能让鼓变成别的鼓或哑掉，需要实测 |
| 4 Ratchet 遇到前一步延续的长音、SFX 时的行为 | **未测（需要 V102 真机）** | 见「未测步骤」3 | 手册：Ratchet 把一步均分成 2/3/4 次，每次重放该步的全部音（§9.11.1）；音效不管按键怎么放都播到结尾，再按一次会重新开始（§6.1.2），所以 SFX 上的 Ratchet 应当是每次重新触发。前一步 Tie & Slide 延续进来的长音如何与 Ratchet 叠加，手册没有写 |
| 5 Chance 是否作用于 SFX；同一 pattern 每遍是否重新抽签 | **通过（手册）**；抽签的随机性本身未测 | 步设置里 Chance 选 95%–5%（SEQ → 该步 SEL） | Chance 是「这一步在多大比例的遍数里发声」，是步的设置（§9.11.1），SFX 与鼓、旋律一样是步里的音，所以一起受它管；手册还把步的设置归在步上而不是某条轨上（§9.12）。「share of passes」说明每遍重新判定。差异：真机是真随机，每次听到的不同；网页要用固定种子保证回放和视频一致，这是网页和真机的不同（见下） |
| 6 串联换 preset 时延迟 / 混响尾巴是否被切断 | **未测（需要 V102 真机）** | 见「未测步骤」4 | 每个 pattern 可设自己的 preset，在该 pattern 第一步前切换（§9.15.2）；每个预设有自己的七个效果（§7）。手册说明：改变效果的类型或开关会重建整条效果链，会切断延迟和混响的尾巴（§9.13.1），而只动它的参数则不会（§7.3.1 Bitcrush 一节）。预设切换本身属于哪种，没有写 |
| 7 自制「HEY」鼓位（Noise + Pulse、短 Decay）能否接近样片听感 | **未测（需要 V102 真机）** | 见「未测步骤」5 | 手册里每个鼓只有一个 Wave（15 种里有 Noise、Pulse 12.5/25/50/75），另有 Snap「鼓音下面叠一层噪音」（§6.2.1、§6.3.2）：Pulse 加 Snap 可以得到 Pulse + Noise，Decay、Pitch、Sweep 可调短、滑音。参数够用，像不像样片靠耳朵 |
| 8 Note Engine 琶音会不会处理鼓键；实时录音相位是否与第 1 步对齐 | **通过（手册）** | 鼓键不需要特别处理；录音见下 | 8‑Bit 上，Auto‑Arp 和 Auto‑Chord 把鼓键和音效键排除在外，每个键仍然只弹自己的鼓或音效（§8.5.1）。part 自带的琶音只作用在贝斯和主奏键上（§6.4），Pattern 里记的是你按的键，播放时才展开（§6.4.4）。实时录音把音落在最近的一步，落在第 1 步前半步内的音记到第 1 步（§9.9）；琶音相位若要和 pattern 对齐，Arp Sync 设 Beat，它每遍从第 1 步重新开始（§6.7）。网站标准模式本来就是步进录入，不依赖实时录音 |
| 9 步锁锁 LD.ARP 时锁的是 Arpeggio 还是 Pattern | **通过（手册）**：锁的是 Arpeggio | 以 Preset 旋钮组的 Lead Arpeggio 上锁（SEL 按住 + 旋钮） | 8‑Bit 预设 Preset 旋钮的八个选项里是 Lead Arpeggio 和 Bass Arpeggio，没有单独的 Pattern 选项（§2.3.1），并且 Preset 组里这八项都可以上锁（§9.13.1）；手册里的例子也直接写 Lead Arpeggio（§9.13.2）。一步最多 4 个锁，Lead Arpeggio 要在预设的四个旋钮选项里（默认就在，§2.3.1）。上锁对 8‑Bit 立即生效（§9.13.3）。**同时发现**：效果的 Type 和开关不能上锁，只有三个数值（§9.13.1），所以「HP」不能锁成 High Pass，只能先在预设里选好 High Pass 并保持开启，再用 Cutoff 步锁；Bitcrush 的 Bits 可以锁 |
| 10 限幅器带来的「伪侧链」是否明显 | **未测（需要 V102 真机）**；机制存在 | 见「未测步骤」6 | 8‑Bit 的鼓、贝斯、主奏共用一个输出，三者合起来超过满刻度下 1 dB 时，整个预设被压低，约 0.2 秒后恢复，三者之间的比例不变（§2.6.3）。所以底鼓会带着低音和旋律一起压一下，有伪侧链的味道；音效是否也被压、压得是否听得出，要听 |

## 手册对编曲的其他影响

核对手册时发现下面两点，不在 10 项之内，Task 6 的导出和 Task 8 的说明要知道：

- **Alberti 不在 31 个内置琶音里**（§6.4.1）。它只是「设了 Key 之后」的 Pattern 选项之一（§6.5.4），或者用 User Arpeggio 自己画 8 步（§6.4.2）。「贝斯 Arp Alberti」因此依赖预设有 Key，和第 3 项里「Key 只改和弦」连在一起看。
- **HP 步锁**见第 9 项：只能锁数值，不能锁滤波类型。

## 未测步骤（以后在装了 V102 的真机上跑）

通用准备：FM-1 装好 Baud Girl V102 并开机，先在 Device Manager 备份，再 `EDIT → Erase Preset → 8-Bit` 初始化一个空预设。除非另写，用 OCT −3 弹鼓、OCT −2 弹音效。每一步的结果和截图路径请补在本节。

1. **鼓位（第 1 项）**：OCT −3，依次按最低 12 个键 F0–E1，记下每个键的声音（底鼓、军鼓、拍掌、闭镲、开镲、镲片、噪音）。`EDIT → Drums` 里每个键对应的行也读一遍。写下 HEY、拍掌、开镲各落在哪个键，鼓位表以此为准。
2. **Transpose 与鼓（第 3 项）**：录一个 pattern：第 1 步底鼓 F0，第 5 步军鼓，另加一个主奏音；播放。(a) 按住 OCT− 或 OCT+ 并转 ALGORITHM 是键盘移调，不是 Seq Transpose，不要混用；Seq Transpose 在 SEQ → Transpose。设 +2，听鼓有没有变、变成哪个鼓、会不会哑。(b) 在鼓所在的那一步里，单步 Transpose 设 +2，同样听。(c) 给两个 pattern 设不同 Key 的预设，听主奏音高有没有变（预期：没有）。
3. **Ratchet（第 4 项）**：在 Lead 轨第 1 步放音并 Tie & Slide 开到第 2 步；第 2 步放另一个音，Ratchet 设 ×4。再在 SFX 轨第 1 步放 Coin，Ratchet ×4、Length 不变。听长音是否被打断、SFX 是否每次重播。
4. **预设切换的尾巴（第 6 项）**：预设 A 开 Delay（Feedback、Mix 偏大）和 Reverb，预设 B 的效果设置相同；pattern 1 设预设 A，pattern 2 设预设 B，Chain 1→2；在 pattern 1 的最后一步放一个短音，听接到 pattern 2 的时候尾巴有没有断。再把预设 B 的 Delay 关掉重来一次，对比。
5. **HEY（第 7 项）**：选一个鼓位，Wave Pulse 50，Pitch 偏高，Sweep 向下，Decay 设短，Snap 加到约一半；弹出来和样片的 HEY 对比。再试一个 Wave 为 Noise、Snap 为 0 的版本，选更像的那个。
6. **伪侧链（第 10 项）**：Mixer 组把 Drums、Bass、Lead 都拉高；放一个底鼓每拍 + 持续的主奏长音 + 贝斯的 pattern，听底鼓出现时旋律和贝斯是否明显被压、约 0.2 秒回升。再把三者调回去，比较什么电平下才开始被压。

## 不通过 / 未测的项：网页保留什么，真机说明怎么注明

原则按设计文档：网页保留效果，真机说明里注明差异。

| 项目 | 网页保留 | 真机说明（Task 8）怎么写 |
| --- | --- | --- |
| 1 鼓位（未测） | 鼓位表先按底鼓 F0、军鼓 F♯0、闭镲 G0，其余按样片放在 F♯0 之后的键上 | 写明「鼓位按 8‑Bit 默认键盘排列，先逐个按键试听，必要时在 EDIT → Drums 里改」，并列出本次实测之后确定的拍掌、开镲、镲片、HEY 键位 |
| 3 升调（不通过） | 样片和视频里第 3 版 drop 升一个全音、第 4 版每句升调的效果，网页里照做 | 不要写「用每个 pattern 的 Key 预设升调」。导出的 .syx 直接把升调后的音写进各 pattern 的音符；真机说明注明：Seq Transpose 是全局的，不要碰它（保持 0）；鼓不要使用单步 Transpose |
| 4 Ratchet 与长音 / SFX（未测） | 网页的 Ratchet 照样片播放 | 写明「卡顿和机关枪的 Ratchet 放在没有延续长音的步上，SFX 步的 Ratchet 听感可能与网页略有不同」，实测后改成确定的结论 |
| 5 Chance（通过，有差异） | 网页用固定种子，保证回放和分享视频一致 | 写明「真机的 Chance 每遍重新随机，闭镲和烟花每次略有不同，不会和视频逐拍一样」 |
| 6 预设切换（未测） | 网页保留各版之间连续的延迟和混响尾巴 | 如果实测被切断：写明「各版的预设使用相同的效果类型和开关，只改参数」；若还是被切断，则注明版与版之间会有一个短的静音 |
| 7 HEY（未测） | 网页保留样片里的 HEY 合成声 | 写明「HEY 由 Pulse 加 Snap 噪音近似，听感与网页接近但不相同」，附实测的参数 |
| 10 伪侧链（未测） | 网页里不额外模拟限幅器，鼓的压感靠鼓与贝斯本身的包络 | 写明「真机在 8‑Bit 三个声部合起来过响时会整体压低约 0.2 秒，鼓密的地方听起来更『泵』，这是机器本身的特点；觉得压得太狠就把 Mixer 的 Drums / Bass / Lead 调低」 |

第 2、8、9 项通过，无需注明差异，但 Task 8 的说明里要提：Rate 的设置因 pattern 而异；HP 步锁要先把滤波类型设好；第 1 版 3/4 用 124 BPM 加 1/8T 近似，约等于 93 BPM。
